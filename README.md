# nfriesen1.github.io

My personal website, built for CISC 375 (Web Development) at the University of St. Thomas and hosted on GitHub Pages.

**Live site:** https://nfriesen1.github.io

## Pages

- **Home:** a short introduction and an "About me" section
- **[Projects](https://nfriesen1.github.io/pages/projects.html):** highlights from my coursework, including a Lego Mindstorms robot that draws letters (AI and Robotics) and a neural-network stock-prediction project (Data Mining and Machine Learning)
- **[Resume](https://nfriesen1.github.io/pages/resume.html)**
- **[Fun](https://nfriesen1.github.io/pages/fun.html):** running and hiking

## Built with

Hand-written HTML and CSS, with the [Foundation 6](https://get.foundation/) responsive framework and jQuery for Foundation's components. There's no build step: GitHub Pages serves the files as they are.

## Running it locally

```bash
python3 -m http.server 8000     # then open http://localhost:8000
```
